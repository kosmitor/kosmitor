# Security policy

Kosmitor stores cap tables, personal data and API keys, so we take security reports seriously.

## Report a vulnerability

Do not open a public issue. Report it privately through GitHub:
[Report a vulnerability](https://github.com/kosmitor/kosmitor/security/advisories/new).

Include:

- what the problem is and what an attacker could do with it,
- the steps to reproduce it,
- the version or commit you tested.

We will confirm that we received your report within 3 working days and keep you
informed while we fix it. Please give us a reasonable time to release a fix before
you disclose the problem in public. We will credit you in the advisory unless you
ask us not to.

## Supported versions

We fix security problems on the latest release and on `main`.
